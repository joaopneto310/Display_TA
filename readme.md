# Projeto: Dominando as Propriedades Display do CSS

---

## 📋 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de estudar, praticar e consolidar o conhecimento sobre as principais propriedades **display** do CSS. Através de exemplos práticos e estruturados, o repositório demonstra o comportamento, as diferenças e as aplicações no mundo real dos seguintes valores:

*   **`none`**: Oculta o elemento completamente da página, removendo-o do fluxo visual.
*   **`block`**: Faz o elemento ocupar toda a largura disponível, quebrando a linha antes e depois dele.
*   **`inline`**: Faz o elemento ocupar apenas o espaço necessário para o seu conteúdo, sem quebrar linhas.
*   **`inline-block`**: Combina características do *inline* (fica na mesma linha) com o *block* (permite definir largura, altura e margens).
*   **`flex` (Flexbox)**: Um modelo de layout unidimensional poderoso para alinhar, distribuir e organizar itens com facilidade dentro de um contêiner.

---

## 💻 Linguagens Utilizadas

*   **HTML5**: Para a estruturação e marcação dos elementos na página.
*   **CSS3**: Para a estilização e aplicação das propriedades *display*.
